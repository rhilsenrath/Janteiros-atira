# Tender investigation
Read the runtime brief and investigate the tender portal using observations. Discover the relevant reference;
never select the first tender merely because it is visible. Read the bill of quantities, units, requirement links,
and applicable documents. Investigate dated Q&A, withdrawn answer numbers, remaining quantity changes and scoped
technical amendments to named revisions. Preserve original clarifications and citations instead of silently
ignoring conflicting or withdrawn records. Capture packaging, delivery, condition-group and setup-pool keys.
Publish the verified reference early with an inspect action and source_ids so Mail can start a targeted search.
Then continue collecting positions and clarifications. Document titles, layout, quantities and identifiers vary.
Never save or submit a bid during investigation. Stop partial when authoritative sources remain unread or ambiguous.
